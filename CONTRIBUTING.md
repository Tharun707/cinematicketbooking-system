# Contributing

Use fictional data, keep credentials outside source control, and follow the root README to run locally. Explain the problem and behavior change in each pull request. Run the API build, frontend build, and lint; report failures honestly. For database changes, include the migration and updated snapshot, then verify startup against a fresh disposable database. Do not commit generated assets, databases, or dependency folders. Security improvements should address server enforcement as well as UI behavior. Confirm licensing and contributor permissions with the owner.
